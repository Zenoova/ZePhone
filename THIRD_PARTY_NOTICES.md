ZePhone's own code is distributed under the licence chosen by its author (none is declared in this
repository yet — add a `LICENSE` file before publishing). It bundles and depends on the following
components. Full licence texts of the native libraries are shipped in the application bundle under
`ZePhone.app/Contents/Resources/engine/licenses/` (generated by `scripts/prepare-baresip.sh`, with a

## Bundled native components (macOS build)

| Component                                                   | Role                                          | Licence                                                                                   |
| ----------------------------------------------------------- | --------------------------------------------- | ----------------------------------------------------------------------------------------- |
| [Baresip](https://github.com/baresip/baresip)               | SIP user agent (sidecar executable + modules) | BSD-3-Clause                                                                              |
| [libre](https://github.com/baresip/re)                      | SIP/RTP/networking library used by Baresip    | BSD-3-Clause                                                                              |
| [OpenSSL](https://www.openssl.org/) (`libssl`, `libcrypto`) | TLS, SRTP                                     | Apache-2.0                                                                                |
| [Opus](https://opus-codec.org/)                             | Opus audio codec (module `opus`)              | BSD-3-Clause                                                                              |
| [spandsp](https://www.soft-switch.org/)                     | G.722 codec implementation (module `g722`)    | **LGPL-2.1** (library)                                                                    |
| libtiff, libjpeg-turbo, libwebp, xz (liblzma), zstd         | transitive dependencies of spandsp            | libtiff licence (BSD-like), IJG/BSD-3/zlib, BSD-3, public domain/0BSD, BSD-3 / GPL-2 dual |

Notes:

- **spandsp (LGPL-2.1)** is linked _dynamically_ (`libspandsp.2.dylib` is a separate file in
  `Contents/Frameworks`), so it can be replaced by the user with a modified build. Its source code is
  available from the upstream project and the Homebrew formula `spandsp`. The upstream project is
  unmaintained (Homebrew marks the formula deprecated): if that is a concern, build the `g722` module
  against `libg722` instead, or ship without G.722 (the app then falls back to Opus/G.711 automatically).
- The bundled Baresip is built from the upstream sources with a single one-line change (module `vumeter`: audio-level
  reports every 60 ms instead of 500 ms, for the call-screen animation), applied by `scripts/build-baresip.sh`.
- **G.711 (PCMA/PCMU)** is implemented inside Baresip (`g711` module).
- The Homebrew bottle of Baresip contains only G.711; Opus and G.722 come from the custom build described in
  the README (`scripts/build-baresip.sh`).
- Patents: G.711, G.722 and Opus are royalty-free to implement at the time of writing; this is not legal advice.
  Check your own distribution context.

### OrbKit (voice orbs)

`src/components/orbs/` contains the WebGL runtime and 14 shader orbs from [OrbKit](https://orbkit.zzzzshawn.cloud)
(<https://github.com/zzzzshawn/orbkit>), MIT licensed, Copyright (c) 2026 zzzzshawn — the licence text is kept in
`src/components/orbs/LICENSE`. OrbKit's other 19 orbs are ported from shaders by @XorDev for non-commercial use only,
with attribution: they are **not** bundled. See `src/components/orbs/README.md`.
